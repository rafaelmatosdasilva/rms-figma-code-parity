# Tidepool components

How each component is used. Kept in GitLab by the design team.

## button
One button per screen, for its main action. Any other action is a link; Tidepool has no link yet.

## chip
Filters a list. People turn it on and off; it never submits anything.

## tag
A status that does not change, next to what it describes. Never a message that comes and goes, like a confirmation or an error: Tidepool has no toast or banner yet.

## field
Only for typing text. Never an on/off control.
