# Tidepool guidelines

Every page opens with one heading in text style m. The page keeps padding/m from its edge and padding/m between its parts.

## button
One button per screen, for its main action. Any other action is a link. Tidepool has no link component yet.

## tag
A status that does not change, next to what it describes. Never a message that comes and goes.

## field
Only for typing text. Never an on/off control.
